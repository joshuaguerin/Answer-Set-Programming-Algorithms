# Problem: Set-Cover


## Description

Given a set S with $n$ elements, that we will call the *universe* and $k$ subsets of S, $S_1, S_2, ..., S_k$, find a selection $S^*$ of the subsets such that all elements of the universe appears at least once in a subset of the selection.

From [Wikipedia](https://en.wikipedia.org/wiki/Set_cover_problem).

### Problem Variants

#### Exact Set Cover

In an exact set cover subset selection, the elements cannot appear twice in two different subsets.
